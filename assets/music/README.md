# Música de fondo

Pon aquí pistas libres de derechos (`.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`).
El motor elige una por producto (siempre la misma para el mismo producto) y la baja
automáticamente cuando habla la voz (ducking).

Fuentes gratuitas con licencia para uso comercial: Pixabay Music, YouTube Audio Library,
Free Music Archive (revisa la licencia de cada pista). Evita música comercial: TikTok
silencia o limita el alcance de videos con audio con copyright.

Los archivos de audio de esta carpeta no se suben a git.
